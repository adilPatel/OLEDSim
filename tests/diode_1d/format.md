## Simulation Output File Layout

Before running a test case, the files in reference_data_raw should be formatted then placed in the appropriate folder for the test case (for example "oled1"). The simulation output files should be formatted as follows:

# Profile Layout

```
Device Name
Band gap at V=0V
Vbi at V=0V

x (nm) | v (V) | potential (V) | n (cm^-3) | p (cm^-3) | muN (cm^2/Vs) | muP (cm^2/Vs)

```

# Figure Layout 

```
Device name
Vbi at V=0V

V-Vbi (V) | J (mA/cm^2)
```
